/api/chat 与 Lark Bot 的边界

共享核心能力，不共享完整 transport

/api/chat 已覆盖

  • NyxID 用户身份和 scope
  • Assistant / AgentRun 与工具目录
  • Ornn 搜索和 skill 加载
  • workflow 启动与 artifact 查询工具
  • SSE 直接返回调用方

Lark Bot 已覆盖

  • Lark webhook 与事件转换
  • NyxID channel relay 和 active Bot
  • conversation 到 agent 的映射
  • 发送者身份解析
  • 文件卡片、附件解析与 reply relay

不能外推

/api/chat 成功不能替代 Lark Bot transport 证据；Lark 回复也不能证明 workflow committed 成功。案例 19 已由 fresh committed 4/4 artifact 独立关闭。Case 20/21/22 已分别取得首次 mount 批准、首次 mount 拒绝和已挂载 workflow 工具批准的独立真实 channel 证据；任一条仍不能替代另外两条，旧失败记录也不能覆盖 fresh committed/typed 结果。
