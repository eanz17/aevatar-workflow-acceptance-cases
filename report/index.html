/api/chat 与 Lark Bot 的边界

共享核心能力，不共享完整 transport

/api/chat 已覆盖

  • NyxID 用户身份和 scope
  • Assistant / AgentRun 与工具目录
  • Ornn 搜索和 skill 加载
  • workflow 启动与 artifact 查询工具
  • SSE 直接返回调用方

Lark Bot 已覆盖

  • Lark webhook 与事件转换
  • NyxID channel relay 和 active Bot
  • conversation 到 agent 的映射
  • 发送者身份解析
  • reply relay 和 Lark 回传

不能外推

/api/chat 成功不能替代 Lark Bot transport 证据；Lark 回复也不能证明 workflow committed 成功。Lark transport 与 typed approval resume 已取得独立证据，但三次 Bot 重试都在 resolve_contact 以 NYXID_PROXY_SERVICE_SCOPE_FORBIDDEN committed failed。Developer App 默认项修复后的 fresh /init 已创建 allow-all consent 与新 binding；Aevatar 显式 core resource 请求仍使 NyxID 在授权码阶段缩窄 binding。
